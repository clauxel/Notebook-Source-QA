# Notebook Source QA

Keep NotebookLM source packs current enough for client-ready answers.

Notebook Source QA imports source packs, URLs, versions, customer projects, and forbidden sources, then tracks freshness, conflicts, missing documents, and client reports.

This is a public documentation project for Notebook Source QA. The structure is modeled after the public documentation pattern used by [MiroFish](https://github.com/clauxel/MiroFish): a short front door, a clear reading order, practical guides, reference pages, and public-safe architecture notes.
