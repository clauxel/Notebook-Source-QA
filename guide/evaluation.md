# Evaluation Guide

Use this page to evaluate whether Notebook Source QA fits a real workflow.

## What To Test

- NotebookLM source pack QA
- NotebookLM source freshness
- NotebookLM enterprise workflow
- NotebookLM client report

## Expected Evidence

- Import files, URLs, version notes, and customer context.
- Check freshness, conflicts, missing materials, and forbidden inputs.
- Route stale or risky sources to owners.
- Export a client-ready update report and recheck schedule.

## Risk Checks

- Do not publish client documents or source packs.
- Redact private source lists before sharing examples.
- Treat freshness checks as workflow evidence, not source-of-truth replacement.
