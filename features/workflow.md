# Workflow

Notebook Source QA imports source packs, URLs, versions, customer projects, and forbidden sources, then tracks freshness, conflicts, missing documents, and client reports.

## Repeatable Flow

1. Import files, URLs, version notes, and customer context.
2. Check freshness, conflicts, missing materials, and forbidden inputs.
3. Route stale or risky sources to owners.
4. Export a client-ready update report and recheck schedule.

## Output Mindset

The useful artifact is not a marketing claim. It is evidence that a reviewer can inspect, export, and compare later.
