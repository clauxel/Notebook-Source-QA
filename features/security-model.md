# Security Model

## Public Repository Boundary

- Documentation only.
- No production source code.
- No credentials or API tokens.
- No customer records or private transcripts.
- No local deployment paths or account screenshots.

## Product-Specific Risks

- Do not publish client documents or source packs.
- Redact private source lists before sharing examples.
- Treat freshness checks as workflow evidence, not source-of-truth replacement.
